# Experiment 2: Responsive Dynamic UI Using JavaScript

## 1. Project Overview

This project demonstrates how to create a responsive user interface that dynamically updates text based on user input using JavaScript.

## 2. Objectives

* Create a responsive webpage using HTML and CSS.
* Update webpage content dynamically using JavaScript.
* Validate user input.
* Implement interactive buttons and event handling.

## 3. Technologies Used

* HTML5
* CSS3
* JavaScript

## 4. Features

* Responsive user interface.
* Personalized greeting based on user input.
* Dynamic text updates without reloading the page.
* Empty-input validation.
* Reset functionality.
* Keyboard support using the Enter key.

## 6. How to Run the Project

1. Open the project folder in Visual Studio Code.
2. Open `index.html` using the Live Server extension.
3. Enter a name in the input field.
4. Click the Update Text button to display a personalized greeting.
5. Click Reset to restore the initial state.

## 7. Testing

The application can be tested for dynamic text updates, empty-input validation, reset functionality, keyboard interaction, and responsive layout.

## 8. Conclusion

This experiment demonstrates how HTML, CSS, and JavaScript can be combined to create an interactive and responsive web application.
